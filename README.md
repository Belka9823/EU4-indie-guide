## 📋 Описание проекта
Сайт состоит из **5 полноценных страниц/разделов** с адаптивным дизайном в средневековом стиле:
1. **Главная (Index):** Вводный гайд, механики эпох и калькулятор Агрессивного Расширения (AE).
2. **Страны (Nations):** Интерактивный каталог государств с поиском и фильтром по сложности.
3. **Великие постройки (Monuments):** База данных памятников архитектуры и их эффектов.
4. **Игровые механики (Mechanics):** Калькулятор военной дисциплины и справочник торговли.
5. **Полезные ссылки (Links):** Ресурсы сообщества и модификации.
